# 🔐 SecureVault

A Flask-based cybersecurity web application designed to provide a secure environment for storing and accessing sensitive files. SecureVault uses authentication, vault-based access control, and protected file handling to reduce unauthorized access to user data.

The project is built around fundamental cybersecurity principles such as **Confidentiality, Integrity, and Availability (CIA Triad)** and demonstrates how security controls can be applied to a file-storage application.

---

## 🚀 Features

- 🔐 User authentication
- 🗝️ Password-protected vault creation
- 📁 Secure file uploading
- 📥 Protected file downloading
- 👁️ Controlled file access
- 🛡️ Authorization and access control
- 🗑️ File deletion and management
- 👤 User-specific vaults
- 🍃 MongoDB database integration
- 🚫 Protection against unauthorized access

## 🔒 Security Concepts

SecureVault was developed primarily as a **cybersecurity-focused project**.

The application demonstrates several important security concepts:

- 🔑 **Authentication** — Verifies users before allowing access
- 🛡️ **Authorization** — Controls access to protected resources
- 🚪 **Access Control** — Restricts access to user-specific vaults
- 📁 **Secure File Handling** — Files are managed through the SecureVault application
- 🚫 **Unauthorized Access Prevention** — Protected resources require authentication and access checks
- 👁️ **Confidentiality** — Sensitive information is intended to remain accessible only to authorized users
- 🧬 **Integrity** — Protecting stored information from unauthorized modification

---

## 🧠 CIA Triad

SecureVault follows the three fundamental principles of cybersecurity:

### 🔒 Confidentiality

Sensitive files should only be accessible to authorized users.

### 🧬 Integrity

Stored information should remain protected from unauthorized modification.

### ⚡ Availability

Authorized users should be able to access their stored files whenever required.

## ⚙️ How It Works

```text
            👤 User
               │
               ▼
        🔐 Authentication
               │
               ▼
        🗄️ SecureVault
               │
               ▼
       🛡️ Access Control
               │
               ▼
        📁 User's Vault
               │
               ▼
       🔒 Protected Files
```

Users first authenticate with SecureVault before accessing protected functionality.

After authentication, users can access their vaults and perform permitted file operations such as uploading, viewing, downloading, and deleting files.
